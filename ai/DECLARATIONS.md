# DECLARATIONS: what was decided (the standard of truth; if the code disagrees, the code wins)

## Stack
- Plain HTML, CSS and JavaScript modules. No framework, no build step. `public/` is deployed as is.
- Conversion: Mediabunny 1.61.3 and @mediabunny/mp3-encoder 1.61.3, vendored in `public/vendor/`.
- Hosting: inside the main website, Netlify project `your-av-dept` (id 7b58fbd4-394f-4091-bc6d-29b4e3b6ff79). `mp3-mp4_app/public/` is copied to the website folder's `just-the-audio/`. The website is deployed with its own `deploy-preview.ps1` and `deploy.ps1`.
- Counter: `site-functions/just-the-audio-count.mjs` and `just-the-audio-stats.mjs`, copied to the website's `netlify/functions/`. Blobs store `just-the-audio-usage` (live), `just-the-audio-usage-test` (test deploys).
- Landing page: `public/index.html`, generated by `tools/build-landing.py` from the website's `library/av365.html`. Never edit it by hand.
- Tests: Node's built-in test runner for logic, Playwright for the browser run.

## Conventions
- The app is served at /just-the-audio/. Paths inside it are relative, except the counter (`/api/just-the-audio/count`) and the service worker (`/just-the-audio/sw.js`).
- Pure logic lives in `public/app/js/queue.js` (no DOM). The engine lives in `public/app/js/engine.js`. The screen lives in `public/app/js/app.js`.
- Errors shown to users are plain English and say what to do or why.
- Colors come from the CSS variables at the top of `public/app/css/styles.css`.
